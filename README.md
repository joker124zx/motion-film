# motion-film

**English** · [中文](README.zh-CN.md)

**A Claude Code skill pack for making videos in code.** Product promos, motion-graphics and style films, Chinese variety-show captions (花字), beat-synced edits, single motion shots — visuals, animation, captions and sound are all generated by code and rendered frame-by-frame, deterministically, to MP4. No video-generation model involved.

## What it teaches the agent

| Part | Contents |
|---|---|
| Directing | Treatment template, three candidate structures, what to take (and not take) from references, camera grammar, transitions, performance and animation principles |
| Timing | Time each beat by the *reads* the viewer has to take in; minimum hold-time formulas for captions, text and logos |
| Aesthetic rules | Case-based rules distilled from real revisions: open on a single hero, no blanket glow effects, at most 3 full-frame hits per film, minimum text height… |
| Product promos | Brand → motion-parameter sheet, full-film skeleton, the real-screenshot trio, a 2.5D page camera, ~30 shot recipes |
| Styles | Executable cards for 15 styles (including the layer structure and parameters of variety-show captions), an index of ~60 styles, and a method for writing or adapting a style |
| Sound | Three sound layers, SFX vocabulary per film type, avoiding the machine-gun effect, music / voice-over / mixing / mastering |
| Beat sync | Fitting a beat grid to the BGM, fixing half/double-tempo errors, time-signature timelines, post-render checks |
| Review | Self-check list plus a ready-to-use independent reviewer prompt and scoring rubric |

## Tools

| File | What it does |
|---|---|
| `scripts/render.mjs` | Page exposes `renderAt(t)` → stills / contact sheets / action strips / crops / MP4; multiple workers, motion blur, vertical video, reading-time checks |
| `scripts/motion.js` | Pure in-page functions: seeded random, CSS-equivalent cubic-bezier, keyframes, springs, overshoot pop, squash, accelerating stagger, beat grid, 2D camera |
| `scripts/sfx.py` | 15 procedural sound effects + event mixing (BGM, ducking under voice); no licensing issues |
| `scripts/master.sh` | Muxing, two-pass loudnorm to −14 LUFS / −1 dBTP, film grain, spec and black-frame report |
| `scripts/beat_grid.py` | Beat-grid fitting + kick/snare/hi-hat classification + energy structure |
| `scripts/capture.mjs` | 2x full-page screenshots of a product page, element cut-outs (transparent / 4x), empty backplates, `layout.json` |
| `templates/starter/` | Runnable starter project; `build.sh` renders the film in one command |

## Install

**As a plugin (recommended)**

```sh
claude plugin marketplace add joker124zx/motion-film
claude plugin install motion-film@motion-film
```

**Or copy the skill folder**: copy `plugins/motion-film/skills/motion-film/` into `~/.claude/skills/` (or your project's `.claude/skills/`).

Then just ask, for example:

> Make a 10-second vertical video in variety-show caption style about my cat stealing the sofa.

> Turn my project (localhost:3000) into a 45-second product promo, cut to the beat of this BGM.

## Requirements

- Node 18+, ffmpeg, Chrome or Chromium (found automatically, or set `CHROME_PATH`); `npm i puppeteer-core` in your project
- Python 3 + numpy, scipy (sound effects); beat analysis also needs librosa (install it into the project's own venv)
- Measured: the 1080p 30 fps starter film — 288 frames, 2-sample motion blur, 3 workers — renders in about 70 seconds; frames are byte-identical across different worker splits

## Principles

- No bundled asset library, no automatically fetching and running code from the network, no auto-updates. When assets need downloading, the agent states their source and license first and records them in `CREDITS.md`.
- Deliverables are the film, captions, treatment, license list and reproducible source — with no promotion or attribution requests attached.
- If you render with Remotion, note that it may require a paid license for companies.

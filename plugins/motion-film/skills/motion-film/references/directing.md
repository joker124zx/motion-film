# 导演：故事、镜头、表演

一支片的评判顺序：**声音、节奏、运镜、导演（表演/调度/情绪弧）**。好看的单帧只是起点。

## 1. 先找标杆

写任何东西之前，为**这个风格 + 这个题材**挑 1–2 部参考作品（电影、片头、广告、游戏、发布会片、知名动态设计工作室的作品）。写下：

- **学什么**：构图、节奏、运镜语法、色彩逻辑、配乐结构；
- **不拿什么**：角色、设计、旋律、具体镜头、logo、字体。

用户给了参考片：ffmpeg 抽帧拼接触印样，逐个动画/转场/特效写成「手法 | 参考片怎么做的 | 采用/弃用及原因」三列表。参考图描述的是“某一类镜头”的感觉，不是全片风格令——逐镜头判断适不适用，不全局套用。

## 2. 故事的形状

- **一个主体、一个目标、一次转折。** 角色（或一个物件、产品、想法）想要什么 → 发生了变化 → 结局和开头不同。
- **前 0.5 s 有钩子，前 3 s 立住。** 开场不放超过 0.3 s 的空画面或黑场；不要先来一段慢吞吞的 logo 揭示。
- **升级 → 高潮（约 60–75% 处）→ 收尾画面**（停住 0.8–1.2 s，带微动）。
- **结尾呼应开头**：同一地点、姿势或母题，但变了；或揭示尺度；或第二次做对。
- **一个“只有这种媒介能做”的瞬间**（native move）：折纸变成转场、墨晕开成下一场、网格吸附成 logo。放在情绪峰值。
- **删掉多余的。** 一个缩略图大小就能读懂的笑点，胜过三个读不懂的。需要解释的节拍就删。
- 第一个冒出来的点子通常是这种风格的陈词滥调；开场画面、结尾和配乐形状从题材里找。

## 3. TREATMENT.md 模板

```markdown
# <片名>
## 候选结构
1. 单程旅途：…   2. 前后对比：…   3. 倒计时 / 逐项清单 / 反转列表：…
选择：<几号>，因为 …
## Logline 与弧线
一句话：<主体> 想要 ___，但 ___，于是 ___。
开端 → 转折 → 结局；情绪关键点（全片规划，不是逐镜头）
## 标杆

## 世界
场景、小色板（3–6 个具体色值）、光、色彩如何随片子变化（例：冷夜 → 暖晨）；母题（反复出现并回收的东西）
## 镜头表
| # | 起止 s | 景别 | 机位 | 运镜 | 事件 | reads（观众依次要读懂的） | 转场入/出 | 为什么这么拍 |

## Cue map
速度/拍网格、每段配器、每个切点/关键动作/字幕落在哪一拍
## 声音设计表
```

检查镜头表：每个镜头有事件吗？每个 read 有时间落地吗？每个接缝有转场吗？结尾呼应开头吗？

## 4. 镜头

- **每个镜头都要有事件**：首帧和尾帧之间有东西变了。“主角站在草地上很可爱”不是镜头。
- **一次一个焦点动作**，剪影清楚，没有东西和它抢注意力。
- **因 → 果**：发生什么，主体就对它反应（一个 take、情绪变化、转向它）。反应往往是最好看的部分，给足时间。
- **埋了就要收**：设置的东西（一扇门、一个声音）要在画面里回收。
- 关键时刻主体至少占画面高度 1/3；不要贴边、不要太小太远；不要同色叠同色（红上红）；字幕不能挡主体。
- **全片至少 4 种不同运镜**并有真实的景别变化。2D 也有相机：推、拉、平移视差、焦点转移、画中画。
- **一个招牌镜头**让人记住：一镜到底、尺度揭示、用媒介本身做的转场。
- **机位服务可读性**：信息密集的镜头（列表、表格、堆叠）正视；含文字的特写用侧向水平机位，不大仰大俯；风格化倾斜逐镜头决定，不全局一刀切。
- 跟随主体的效果（光圈、推近、聚光）一律走同一个“世界坐标 → 屏幕坐标”函数，不手写屏幕坐标，否则相机一动就跟丢。

### 运镜语法（通用词汇表，按片子取用）

| 运镜 | 表达 | 可用于 |
|---|---|---|
| 缓推 | 紧张、聚焦、“就是这个细节” | 揭示关键；倒计时；决定前 |
| 缓拉 / 拉远到全貌 | 尺度、退后一步看清规则 | 总结；结尾；“原来这么多” |
| 横移视差 | 旅程、时间流逝、浏览 | 清单；流程；路线 |
| 锁定不动 | 判断、阅读时间、庄重 | 数字落定；标语；决定 |
| 甩镜 + 拖影 + 过冲回稳 | 惊讶、超出预期 | 纪录；异常值；转场 |
| 环绕（orbit） | 体积、物件特写、审视 | 产品/物件主角 |
| 升降（crane） | 宏大、收尾峰值 | 发布会式结尾 |
| 跟镜头 | 陪伴、动作连续 | 角色奔跑；元素飞行 |

## 5. 转场

- **每个接缝都要有转场**：进第一个镜头、每两个镜头之间、出最后一个镜头。不要硬起、不要突然停。
- 转场属于故事和媒介：色块/笔刷擦除、形状光圈、甩镜拖影、**匹配剪辑**（形状或运动跨切点延续）、**动作中切**（动作做一半切，下一镜做完）、贯穿两镜的运镜、从纸/黑推入。不要每次都用同一种。
- 普通硬切只在动作中切或刻意的 smash cut 时可以。
- 默认的淡入淡出（crossfade）几乎总是偷懒；转场由画面元素承担。
- 镜头内部的变化也是转场：表情变化要演出来、转身要经过关键视图、道具沿弧线进出，不凭空出现。
- 动作连续、屏幕方向一致（主体向右走，下一镜继续向右）。

## 6. 表演与动画原则

代码写出来的运动天然机械：所有部件同时动、同一条曲线、同样幅度。下面每条都在修这个问题。

- **预备**：大动作前先反方向小动作（起跳前下蹲、投掷前后摆、惊讶前眯眼）。它告诉观众“要来了、往哪看”。
- **挤压拉伸**：撞击时压扁、快速运动时拉长，体积守恒。
- **缓入缓出**：几乎没有东西匀速运动；进度先过缓动函数。
- **重量**：重的起步慢、停得慢、落地少弹；轻的一下就动、会弹会飘。
- **弧线**：活物走弧线不走直线（抛物、跳跃、摆臂、转头）。
- **重叠与跟随**：眼睛先动、身体跟上，手臂/帽子/道具/尾巴拖后、过冲、最后落定。每个部件比它挂着的那个部件晚一点。
- **避免双胞胎**：代码爱复制数值——两臂同角度、双眼同时眨、一群元素同步弹跳。给一边主动作、另一边小动作；相位、时间、种子都错开。
- **夸张**：姿势、反应、挤压比“自然”再推一步。短片里含蓄等于没有。
- **关键姿态先读得懂**：每个讲故事的姿态当静帧看就能读懂，再补中间运动。姿态读不懂，运动救不了。
- **展示思考**：注意到 → 想 → 行动，眼睛先动。观众看到“做决定”才理解选择。
- **次要动作**：帽子晃、表情符号弹出、草动——添生气，但不抢主动作。
- **永不静止**：每种情绪有自己的待机微动，相机轻推或漂移，背景有呼吸。完全冻住的帧读作 bug（刻意的定格除外）。
- **表情要演，不要切换**：情绪变化经过预备、眯眼、反应、过冲；不在两帧之间直接换眼睛嘴巴。“担心”和“生气”只差眉毛一翻，按最终尺寸检查。
- 角色姿态混合一律用关键帧 + 缓动，不在 `if` 里切换姿态（刻意的一帧喜剧跳变除外）。手持的道具在两掌之间、深度在两臂之间；滚动物体转角 = 距离 ÷ 半径。

## 7. “别再做一遍样片”

读过任何样片/模板的源码后，对照六项：结构、开场、招牌镜头、运镜路线、配乐形状、结尾。**至少四项要不同**；相同的重新想。样片的故事、道具、配色、时长都不是模板。

## 8. 最常见的失败

- 主体太小、太远、贴边；太暗看不清；同色叠同色；
- 字幕挡主体；笑点/失败太快看不懂；
- 所有东西一个速度、事件叠在一起、没有停顿；
- 转场里出现空白帧；
- 跟随效果在相机动后跟丢；
- 招牌和字卡在复述故事（举个牌子写“我迷路了”）——要演出来；
- 每个镜头一个世界，彼此毫无联系。

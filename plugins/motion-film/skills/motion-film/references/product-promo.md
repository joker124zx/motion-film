# 产品宣传片

适用：网站、Web App、桌面/移动 App、前端项目做成 15–60 s 宣传片或功能演示片。
与 directing / timing / aesthetic-rules / sound 一起用；本文件只写产品片特有的部分。

## 1. 产品检查（只读）

开工前对项目做一次最小、只读的检查，不改业务代码、不采集敏感数据：

- 定位与目标用户；核心卖点；主要功能和对应路由/页面状态；
- 怎么跑起来（dev server 命令、需要的环境变量、能否用 fixture/seed 数据）；
- **设计 tokens**：从设计系统、CSS 变量、Tailwind 配置或 computed styles 提取字体家族与字重、字号层级、行高字距、栅格与间距、圆角、背景/表面/正文/强调/状态色、渐变与材质；
- 数据风险：页面上有没有客户名、个人信息、内部地址、密钥、实时数据。

产出写进 TREATMENT.md：

- **产品简报**：用途（官网首屏 / 发布会 / 社媒 / 投放）、受众、核心卖点、必须展示的功能、时长/画幅/语言、音频要求、数据口径；
- **需求 → 执行决策表**：每条需求落到哪个镜头、什么页面状态、什么素材、什么文案。

## 2. 视觉方向：从产品长出来

- 片中所有标题、字幕、字卡、转场、粒子、光效的字体与配色**复用或克制扩展产品 tokens**。借用镜头配方时只借运动语法和节奏，字体排版配色材质按产品重新“蒙皮”。偏离产品视觉要写明理由。
- 最多 3 个文字方向，每个附一组动效性格 tokens（下表），选一个并写下取舍。
- 用纯 HTML/CSS 做 2–3 张 1920×1080 风格帧截图定调，**不用渲染视频做风格提案**。有严格品牌规范或明确参考片可跳过，写明理由。

### 品牌 → 动效参数

先把品牌放到两根轴上：**能量**（沉稳/机构 ↔ 运动/娱乐，决定时长、过冲、挤压幅度）和**调性**（严肃/金融医疗 ↔ 活泼/消费社交，决定路径曲直、次要动作多寡）。产品视觉本身是证据（锐利几何 → 工程感；圆角亮色 → 活泼），用户口述的品牌词优先。

| 预设 | 主时长 @30fps | 入场缓动 | 过冲 | 挤压 |
|---|---|---|---|---|
| 专业信赖（fintech / B2B / 企业） | ~21 f | cubic-bezier(0,0,0.2,1) | 不弹 | 0 |
| 精致高端（奢侈品 / 时尚） | ~48 f | cubic-bezier(0.4,0,0.6,1) | ≤ 1.02 | 0 |
| 活力大胆（运动 / 游戏 / 创业） | ~18 f | cubic-bezier(0.16,1,0.3,1) | 1.12 | 0.25 |
| 活泼愉悦（消费 / 社交） | ~27 f | cubic-bezier(0.34,1.56,0.64,1) | 1.08 | 0.18 |
| 平静关怀（健康 / 教育） | ~42 f | 对称 ease-in-out | 不弹 | ≤ 0.04 |
| 亲和友好（小微 / 社区） | ~26 f | cubic-bezier(0.25,0.46,0.45,0.94) | 1.04 | 0.08 |

一个品牌一种动效嗓音：同一套 tokens 同时管入场、转场和停留节奏。自检：用三个词描述成片的动效，和品牌词对得上吗？
注意：“不弹”指没有落地隐喻的淡入/推移；有落地动作的元素仍然要过冲（y1 > 1）。

## 3. 全片骨架（默认，可偏离）

| 段 | 占比 | 能量 | 职责 |
|---|---|---|---|
| ① 品牌开场 | 8–12% | 低 | 字标出现 + 停 ≥ 1 s，交棒产品页面 |
| ② 单主角立传 | 12–15% | 中（质感最高、节奏最慢） | 一个主角（一张卡/一个模块）+ 完整动作弧 ≥ 3 s，立住“产品的原子单位” |
| ③ 功能爬升 | 55–65% | 中高 ⇄ 低交替 | 每镜一个独特功能，一种手法只当一次主角；每 1–2 镜插一张呼吸字卡（约 1.8 s，全片 2–4 张） |
| ④ 发布会收场 | 13–16% | 全片峰值 | 已展示功能各出一个代表元素围住字标（Q8），落定停 ≥ 1 s |

填法：列功能清单 → 扣掉 ①②④ 和字卡预算 → 剩余均分给 ③；**每镜先划走 hold 帧再排动效**。③ 段高能镜（发牌、堆叠）与稳节奏镜（交互、读字段）交替；信息密度最高的镜头（文档、报告）放在收场前倒数第 2–3 位。15 s 短片或单功能产品可合并段位，但开场停留和收场峰值不可省。呼吸字卡不能写成第二遍标语。

## 4. 素材采集（分镜定稿后再做）

复刻真实页面必须截图（aesthetic-rules Q1）。`scripts/capture.mjs` 产出三件套：

- **全页 2x 截图**：视口 1920×1080、`deviceScaleFactor: 2`；截图前等 `document.fonts.ready` + 600 ms；实时同步页面再多等 1.5–2 s；
- **元素切图**：按语义选择器逐元素截，浮起的芯片用透明底；需要“元素飞入空板”的镜头额外截一张隐藏这些元素的空底板；
- **layout.json**：每个元素在整页坐标系里的 `{x, y, w, h}` 和每页高度——飞行终点、遮罩、聚光位置都从这里取，不手量。

先注入虚构但真实感的演示数据（seed 脚本 / fixture 环境），空库或 lorem ipsum 截出来直接废片；真实客户数据不能出片。数据在采集前冻结。

桌面/移动 App 用窗口截图或模拟器截图，同样产出三件套。

## 5. 页面相机（2.5D）

一切“真实页面”镜头的地基：一张整页纹理平面 + 关键帧 2.5D 相机（位置、zoom、rotX/rotY、透视）+ 页面空间里的 overlay 层（光标、高亮、注记、飞入元素，按页面 CSS px 定位，与 layout.json 共坐标系）。

- 放大用 CSS `zoom` 让浏览器按放大后的尺寸栅格化，不用 `transform: scale` 放大位图（Q2）；
- 推近期间用主角元素的 4x 单独截图交叉淡入（约 6 帧）；
- 遮罩、暗场、光池放在页面空间（随相机透视），屏幕空间的遮罩跟不上透视和元素抬升；
- 抬升的元素 translateZ 至少比暗场高 2 px，否则共面闪烁；
- 推进落定后相机锁死，别留“尾漂”——呼吸交给光，不交给相机。

## 6. 镜头词汇（按用途挑，一种手法全片只当一次主角）

时长按 30 fps 给参考值；数字是起点，不是令。

**开场**

- *聚光主角卡*：关灯的页面（整页压到 6–14% 亮度，保色相）→ 聚光游走 2–3 站后锁定一张卡 → 斜侧推近（rotY 约 34°、rotX 约 8°）→ 卡弹起悬浮（过冲 + sin 轻浮）→ 轮廓光束绕两圈（第一圈快亮、第二圈慢弱）→ 落回原位压一下。约 5–6 s，落地后真静止 1 s。声音：推闸 clunk / 弹起 whoosh / 扫描 sparkle / 落定 snap。
- *字标压印*：墨线描画十字或轮廓 → 字标逐字压印 → 打字机副标 → 静止满 1 s 再上浮交棒。
- *断笔成字*：标题拆成十几段笔画乱序点亮，前 70% 不可读，最后一笔落位瞬间语义出现。
- *升降揭示*：开场贴着一行数据特写，相机沿纵轴减速升起后拉，一行行涌入直到整个仪表板。
- *图标点阵上色*：灰阶小图标错峰铺满全屏，停一拍后品牌色横带波纹扫过全场——“功能很全”。

**功能段**

- *发牌飞入*：牌堆特写环绕开局，一摞卡像发牌一样硬加速飞向页面槽位，越来越快，满板后静止 0.5 s。
- *打字筛选*：真实 UI 搜索框按真人速度打字 → 网格收敛到一张卡 → 点击穿透进详情页。
- *列表压摞*：卡片从底部逐张飞上摞起，每张落地压弹整摞，计数器同步跳一格。
- *行嵌入*：内容行从空中降下、rotateX 收平，嵌入瞬间底边亮一道强调色细缝。
- *文档自写*：整页真排版文档在光标后自己“写”出来，侧栏跟进（配打字声，Q10 出版级）。
- *光标巡航*：整页俯瞰后相机依次飞到功能区特写，光标先一步到位指点、点击留涟漪。
- *前后对比拉杆*：两版叠放，分割杆先猛甩后慢扫，杆过处新版显影。
- *图表活体*：数值滚动（随机跳 3–5 帧后落真值）、仪表满弧自检扫针、示波流线实时写入。
- *扫描取景*：一条扫描线自上而下掠过页面，越过哪块，哪块就被四角取景框框住并标注。
- *3D 翻面*：功能卡沿 Y 轴翻 180°，最薄处掠过一道随角度移动的受光。
- *协作光标*：多个光标错峰飞入、正弦漂移、聚拢围观——多人协作的氛围层。
- *主题切换扫场*：一道斜向边界扫过，经过处就地换肤。

**文字**

- *模糊滑入*：逐词 y 0.38em→0 + blur 18→0 + 透明度 0→1 三通道同一条 ease-out，词间隔约 4 帧。
- *马克笔下划线*：标题落定后关键词下方一笔毛糙马克线从左到右描出，微上斜。
- *词槽轮换*：句干钉死，句尾胶囊里的词老虎机式滚动，胶囊宽度随词宽平滑插值。
- *误删重打*：打出平庸词 → 犹豫 → 退格 → 更快打出卖点。
- *呼吸字卡*：一句话逐词压印上纸，一个词用强调色，短划线收束。

**转场**

- *圆心匹配光圈*：光圈从页面圆形元素的圆心炸开，圈内新页的圆形接在同一个圆上。
- *线条接力*：A 场景的进度条延伸出画，镜头跟线横移，线拐弯围出 B 场景的卡片。
- *藏切点*：硬切藏进前景遮挡、对撞或漏光峰值的 1–3 帧里。
- *甩镜*：带方向拖影的急刹甩镜，按两镜能量落差选。
- *底边上推*：新场景整屏从底边推入，把旧场景物理顶出。

**节奏手法**（计入 R4 名额）

- *三连闪*：三次白闪各硬切同一画面的一个裁切（全景 → 卡片 → 特写）。
- *预告片速剪钩子*：三镜各 9 帧速剪 + 黑场静默一拍，再出标题。
- *速度变形定格*：流动 → 定格圈注 → 解冻。

**收场**

- *发布会合影*（Q8）、*UI 层层蒸发只剩一颗按钮*、*图标翻扁成竖线再撑开成品牌标志*、*颗粒凝聚成字标*。

## 7. 交付

- 带 BGM 版 + 无 BGM 版（保留音效），从同一时间线渲出，不后期抽轨。
- 独立评审额外检查：功能清单每项是否有清楚的镜头；视觉是否漂离产品 tokens；有无未经确认的功能宣称；数据是否已脱敏；截图字体图片是否完整加载。

# 声音

## 1. 顺序

画面结构锁定 → 音乐定能量骨架 → 逐个钉音效 → 配音/字幕 → 混音 → 母带。
声音是时间线级资产：全部集中在一个文件管理（`mix.py` 或一张事件表），场景代码里不写音频。
例外：用户给了 BGM 要卡点 → 先分析音乐（`beat-sync.md`），画面锚到拍上。

## 2. 三层

| 层 | 内容 | 要点 |
|---|---|---|
| 环境 | 房间底噪、风、雨、城市、显示器嗡声 | 每段有自己的底；转场时可提前进/拖后出（J/L-cut） |
| 拟音 | 绑定画面动作 | **每个可见动作都有声音**：落地、翻页、点击、滴落、布料。材质要对（纸、木、金属、墨、玻璃各不同） |
| 音乐 | 能量骨架 | 用风格的配器；避免泛用“钢琴加弦乐” |

人声/关键拟音出现时，音乐压低（ducking）。

## 3. 音效词汇

- **产品/科技片**：whoosh（运镜、飞入）、impact（落地、字标）、riser（铺垫）、sparkle（光效余韵）、transition（转场）、真实拟音（快门、机械开关、键盘）。收尾固定句式：**riser → impact（全片音量峰值）→ sparkle 余韵**。强鼓点 BGM 下音效要克制：鼓本身就是节拍音，音效只钉画面独有的动作。
- **综艺/萌宠/搞笑**：boing、pop、ding、滑哨、唱片刮擦、拍手；这里“游戏感”音色恰恰是对的。
- **手绘/纸艺/手作**：纸张摩擦、铅笔、剪刀、胶带、木头敲击；音量小而近。
- **HUD/科幻**：数据流 tick、扫描 sweep、锁定 beep（可以合成，但要干净短促）、低频嗡。
- 原则：音色按片种选（aesthetic-rules S1），动作配它真实的声音（S4）。

## 4. 音效表与防机枪

```python
# 每条一个动作；时间写相对表达式（镜头起点 + 偏移，或拍号），不写裸数字
SFX = [
  dict(at=T['hero']+0.10, kind='whoosh', gain=0.5, note='主角卡弹起'),
  dict(at=T['hero']+1.85, kind='impact', gain=0.7, note='主角卡落回原位'),
] + [
  dict(at=T['grid']+t, kind='pop', variant=i % 2, gain=0.40 - 0.03*i, note=f'第{i}张卡落位')
  for i, t in enumerate(accel_times(6, total=1.2))   # 间隔随动画加速
]
```

连发三招：双样本交替、音量阶梯递减、间隔跟着动画曲线加速；太密时淡成一道 swoosh。
长样本必须裁到动作等长；带长尾的 impact 让尾音自然衰减。

## 5. 素材来源

**首选合成**：`scripts/sfx.py` 能程序化生成 whoosh / impact / riser / pop / click / tick / sparkle / thump / paper 与噪声底，零授权问题，时间精确到采样。合成的问题是容易“太干净太电子”——加一点噪声、滤波包络、立体声展宽和短混响。

**需要真实录音/乐器时**（下载前先告诉用户下什么、从哪、什么授权，并记进 CREDITS.md）：

## 6. 原创配乐（无 BGM 时）

- 从 cue map 写谱：事件形式 `(时间, 乐器, 音高, 时值, 力度, 声像)`，与画面读同一份时间线。
- 采样乐器用 round-robin（同音多个样本轮换）避免机枪感；拨弦类可用 Karplus–Strong 物理建模；芯片音乐、drone、氛围用 numpy 合成。
- **低频平衡**：合成配乐容易低频过重。混完按频段量能量，20–120 Hz 相对其余约 −3 dB；pad 不低于 MIDI 48；贝斯加 2、3 次谐波，小喇叭上才听得见。
- 结构跟画面能量曲线：低开 → 推进 → 峰值；高潮前留静音（S6）。
- 产品片有 BGM 时，BGM 用一个开关单独挂载，终渲出“带 BGM / 无 BGM（保留音效）”两版。

## 7. 配音（TTS）

- 用户有自己的录音或指定声音，就用那个。
- 中文：edge-tts（微软在线神经语音，如 `zh-CN-XiaoxiaoNeural`、`zh-CN-YunxiNeural`）效果好但**需要联网**，用前告诉用户；离线方案（如 Kokoro）中文听感较平。英文离线 Kokoro 可用。
- TTS 文本里数字写成读法，字幕里写阿拉伯数字。
- **每句回读校验**：用 faster-whisper 转写每条 WAV 与脚本比对（中文逐字），不一致就重生成；短句错一个字常见，自己听确认正确后可放行。转写同时给出词级时间戳，用于对字幕。
- 混音前先压缩人声（TTS 峰均比高），再按 RMS 平衡：人声比音乐高约 10 dB。

## 8. 混音与母带

- 先在混音里做 ducking、压缩、平衡，导出 `mix.wav`（48 kHz 立体声）。
- `scripts/master.sh video.mp4 mix.wav out.mp4`：两遍 loudnorm 到 −14 LUFS、真峰值 ≤ −1 dBTP，打印实测响度，并做黑帧检测与规格报告。
- 颗粒（grain）在 ffmpeg 里加，不在页面里画：页面里画的颗粒让每帧都不可压缩、渲染又慢。像素/矢量风格不加颗粒；浅色背景少加。
- 闭眼只听音轨自检：像这个片种该有的样子吗？（产品片像发布会预告，不像手机游戏；花字片像综艺，不像广告。）

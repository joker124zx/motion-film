# 卡点：BGM 节奏分析与拍号时间线

用户已选好强节奏 BGM 时启用。**铁律：音乐先行**——网格验收通过之前不分镜；时长对不上改时间参数，不删用户文案。全程用浮点秒记录，换算成帧只在最后一步。

## 1. 跑分析

```bash
python3 -m venv .venv && .venv/bin/pip install librosa scipy soundfile   # 装进项目自己的 venv
.venv/bin/python scripts/beat_grid.py bgm.mp3 analysis/beat_data.json
```

脚本做四件事：

1. `beat_track` 拿到拍点序列后，**对整个序列做最小二乘等距拟合** `t_i = t0 + i·T` 求真实 BPM 和相位。（`beat_track` 返回的 tempo 标量可能偏 2% 以上，但拍点序列本身是好的。）残差 ≤ ±15 ms 说明是机器鼓点、网格可信；残差大说明有变速，要分段拟合。
2. **倍数歧义**：拍点检测常锁错到 2x、0.5x，甚至 3:2（实测一条 124 BPM 的鼓轨被报成 82.7）。脚本把 0.5x / 0.67x / 0.75x / 1x / 1.33x / 1.5x / 2x 七个候选各自重新拟合相位，按“网格命中率 × kick 覆盖率”的 F1 选。判据是数据不是听感——正确网格下 kick 主要落在整数拍上。
3. **三分类瞬态**（在打击成分上测，`hpss` 分离；人声贝斯很厚的曲子可先用 Demucs 分离鼓轨）：

   | 类别 | 频段 | 驱动 |
   |---|---|---|
   | kick | 40–160 Hz | 冲击/落地——“被砸”的一拍（候选，见 R4） |
   | snare | 150–500 Hz 加 1–3 kHz | 替换、闪切、构图切换——“换一件事” |
   | hihat | 6–14 kHz | 微动密度：hihat 密的段落微动可以密，稀的段落要收 |

4. **RMS 能量曲线 → 结构表**：满能量从第几拍起、breakdown 在哪；以及**最强 hit 拍号清单**（全片 2–3 个大 slam 只能钉这些拍）。

## 2. 网格验收（先验收后分镜）

| 指标 | 门槛 |
|---|---|
| match：网格拍命中真实瞬态的比例 | ≥ 98% |
| 平均绝对对齐误差 | < 10 ms |
| 漂移：残差对时间回归的斜率 × 时长 | 全曲累计 < 5 ms |
| 第 0 拍落在真实的音乐攻击上 | 必须 |

拿不准时把候选网格合成 click 轨叠回原曲听一遍，但以指标定夺。分析结果连同所有候选和获胜理由留档在 `analysis/`。

## 3. 时间线用拍号写

```js
const BPM = 131.97, BEAT0 = 0.2244;          // 来自 beat_data.json，审计真值，不改
const AUDIO_OFFSET = 0;                       // 渲后实测的输出音轨偏移另记，不混进 BEAT0
const T = 60 / BPM;
const beatT = (n) => BEAT0 + AUDIO_OFFSET + n * T;   // 拍 → 秒
export const SHOTS = {
  open: { t0: 0,         t1: beatT(8)  },
  slam: { t0: beatT(8),  t1: beatT(16) },
};
```

换曲时改两个常量全片重排；音效表也写 `beatT(n)`，与画面同源永不错位。

**锚点规则**：

- 密集规则切点（每拍/每两拍）→ 用网格；
- 稀疏重音、孤立定格 → **钉真实瞬态**，不用网格插值（单个重音会放大网格微漂移）；
- 结尾定格 → 最后一个真实瞬态 + RMS 静默确认（别钉在余韵尾巴上）；
- 视频素材/音效按**内部峰值**对齐，不按文件头。
- 强鼓点曲的重音几乎都在整数拍上；半拍钉点必须有能量数据支持，不能凭感觉（实例：钉在两拍之间，回测偏了近 6 帧）。

**设计规矩**：

- 镜头以拍为单位（4/8 拍一镜），加速段用半拍/四分之一拍阶梯收敛（如切点在 48, 49.5, 50.5, 51, 51.25 拍）。
- 每拍一动作的步进镜头（清单逐项、马赛克逐格）直接映射拍号——步进的是内容，不是画面幅度。
- 全画面冲击硬上限见 aesthetic-rules R4。卡点动效默认落在主角元素层。
- 结构性运动（形变、运镜）用连续函数；冲击事件（出现、替换、闪）在选定那一帧开关。多层同帧命中构成重音；错开只能是 1–2 帧的刻意设计，不能来自取整误差。

## 4. 渲后回测（必做）

成片抽出音轨，对每个设计切点找最近的真实瞬态，报两种误差：

- **音频真值误差**：设计切点（秒）vs 原曲真实瞬态（秒）——验分析和设计；
- **成片误差**：成片里画面切点帧 vs 成片音轨里的瞬态——额外包含输出编码偏移（aesthetic-rules S5）。

全部切点误差 ≤ 3 帧才算过（感知阈值约 3 帧）。如果成片误差有一致的偏移，测出来填进 `AUDIO_OFFSET`，不逐条改。

画面切点可用 ffmpeg 场景检测抓：`ffmpeg -i out.mp4 -vf "select='gt(scene,0.3)',showinfo" -f null - 2>&1 | grep pts_time`。

# 风格图谱

两部分：**A. 15 种风格的可执行卡片**（标志特征 + 关键技法参数 + 技术路线 + 声音），**B. 更多风格的一句话索引**。
用户点名风格 → 先在这里找；找不到或要深做 → 按 `style-spec.md` 现场写一份完整风格说明。
卡片里的数字是起点。**标志特征是验收依据**：专家应在一秒内认出这种风格，每条标志技法都要出现并做对。

---

## A. 风格卡片

### 扁平矢量 Flat Vector
- **是什么**：纯色几何化人物与场景、无描边或极简描边、大色块撞色。企业解说片/SaaS 宣传的基本盘。
- **标志**：纯色大色块、几何化角色、几乎无渐变、干净留白、高饱和品牌色板、元素弹性进出。
- **技法**：过冲缓动是灵魂 `cubic-bezier(0.34,1.56,0.64,1)`，入场“预备—冲出—回弹”三段；错峰 2–4 帧，同一时刻只让一个主体动；位移带约 10% 挤压拉伸；四肢用锚点旋转做 rig；转场用色块擦除或元素飞出带走整场。
- **路线**：SVG + 缓动库（或手写），快动作开 4 样本运动模糊；30 fps。
- **声音**：明快 future-bass/pop 约 120 BPM；每次入场 pop / boing / whoosh。

### 线条动画 Line Art
- **是什么**：单色细线是唯一造型语言，线自我描绘、延伸、转折并变成下一个图形，一笔连成整支片。
- **标志**：等宽细线、单色或双色、大量负空间、线条连续生长、线转面的瞬间。
- **技法**：`stroke-dasharray/dashoffset` 配 `getTotalLength()`；全片线宽恒定 2–4 px；转角处描绘稍减速，`cubic-bezier(0.65,0,0.35,1)`；上一图形的尾线就是下一图形的起线（路径提前连好）；描完轮廓后同路径填充从锚点扩开；圆头端点 + 微抖动加手绘感；虚拟相机跟随笔尖。
- **声音**：毡音钢琴 + 弦乐渐强；笔尖摩擦声音量跟随笔速；填充时一记轻铃。

### 等轴 2.5D Isometric
- **是什么**：30° 等轴测微缩世界（城市、办公室切片、机房），无灭点、处处等比。
- **标志**：等角投影、无透视、微缩场景、楼房生长、平行滑轨式运镜。
- **技法**：SSR 造面——纵向缩放 86.6% → 斜切 ±30° → 旋转 ∓30°；Z 序 = 画面 y 坐标；沿网格移动保持 2:1 像素斜率；楼房生长：底面先落位，立面 scaleY 从 0 拉起，顶面晚 2–3 帧盖上；运镜整组平移不旋转，前中后景视差 1 : 0.8 : 0.6。
- **路线**：Three.js 正交相机（真等轴角）+ 软阴影 + AO，或 SVG 矩阵面。
- **声音**：明亮拨奏科技旋律（FM 马林巴）；每块落地轻 click/pop；拉远时一道气声 whoosh。

### 3D 渲染系 CGI
- **是什么**：软胶、玻璃、金属、布料的实体质感 + 克隆阵列 + 物理模拟，高端产品片和品牌 ident 主流。
- **标志**：PBR 材质、浅景深、柔和棚拍布光、阵列、软体碰撞、糖果色软胶。
- **技法**：阵列 + 效果器做群体波浪；质感三件套 SSS（软胶感）+ AO + HDRI 三点光；长尾缓动——前 20% 时间走完 80% 路程，收尾极慢，配运动模糊；24 fps + 浅景深（f/1.8 感）；产品为轴心，粒子/流体/布料围绕它编排。
- **路线**：Blender 命令行 bpy 脚本 → Cycles（降噪）→ PNG 序列 → ffmpeg；文字可另用 HTML 叠一层。或 Three.js + 后期景深/AO，2x 渲染后缩小。
- **声音**：ASMR 式软撞击、挤压、气泡 pop、空气感氛围垫；命中帧级同步。

### 逐帧手绘 / 线条沸腾 Cel & Line Boil
- **是什么**：手绘逐帧质感，线条每隔几帧轻抖，画面像在呼吸；反数字精致感。
- **标志**：线条持续微抖、一拍二/一拍三节奏、smear 拖影帧、手绘烟火水花点缀、纸纹底。
- **技法**：24 fps 下一拍二（实际 12 fps）为主，快动作一拍一，静止镜头一拍三；boil = 3–4 张微差线稿循环（或每 2 帧换随机种子的位移）——**静止元素各用自己的种子**，否则一个动的元素会让后面画的东西全部乱抖；smear 帧把快速位移的物体拉长 150–300% 只留 1 帧；烟、水花、闪电用逐帧手绘叠在主体上；整体叠纸纹（multiply 10–15%）。相机和光每帧平滑，不跟着一拍二（阶梯式相机读作卡顿）。
- **路线**：Canvas2D 自写变宽笔刷（中线 + 压力 → 轮廓多边形）；或 p5.js + p5.brush（水彩填充很吃 GPU，无独显时换别的填充）。
- **声音**：俏皮爵士拨弦/木琴 + 卡通音效（strike、fwoosh、pop、poof、sparkle）。

### 拼贴剪贴 Collage / Cutout
- **是什么**：老照片、报纸、手撕纸片剪下来重新拼装的复古超现实风格。
- **标志**：照片剪影白描边、半调网点、报纸纹理、比例失衡的超现实拼装、定格式抽帧。
- **技法**：抠图加 2–4 px 白描边 + 半调滤镜；关节锚点在肩肘颌，分段旋转，嘴用两三张替换帧开合；主体 12 fps 甚至 6 fps，位置 ±2 px 抖动模拟手摆；层次：纸纹底 → 大色块 → 照片剪影 → 涂鸦/胶带贴纸 → 颗粒；转场用“手把元素拍上来”或翻纸。
- **路线**：DOM/Canvas + 公有领域照片抠图（rembg 等本地抠图）；按 12 fps 网格保持动作，30 fps 输出。
- **声音**：黑胶噼啪、爵士 boom-bap、纸张摩擦、剪刀声、拍打声。

### 液态流动 Liquid
- **是什么**：图形像液体一样流动、拉丝、滴落、融合，logo 从一滴液体聚合成形。
- **标志**：波浪边缘转场、拉丝与滴落、metaball 融合、次级液滴跟随、永不直线。
- **技法**：转场遮罩前沿是波浪形，加 3–5 个错相凸起；metaball 伪造：高斯模糊 20 px 以上 → alpha 阈值（feColorMatrix），两球靠近自动粘连；拉丝—断裂—回弹：离开时留细颈，断裂瞬间两端各回弹 2–3 帧；缓动 `cubic-bezier(0.22,1,0.36,1)`（液体是被甩出去的）；次级液滴晚主体 2–3 帧，落地压扁。
- **路线**：WebGL2 片元着色器：2D SDF metaball（smooth-min）+ 场梯度法线做假 3D 光照，logo 用文字 SDF。
- **声音**：咕噜、倾倒、飞溅、滴落、深低频涌起 + 光亮合成底。

### 形变 Morph
- **是什么**：一个图形丝滑连续地变成另一个（手机变地图钉、咖啡杯变落日），图形叙事的核心语法。
- **标志**：轮廓连续无跳变、中介形状桥接、形变伴随位移旋转、变形瞬间挤压拉伸。
- **技法**：两形状顶点数一致、首顶点方位对应，否则打结；复杂 A→B 先收敛成中介简形（圆/胶囊）再展开，两段各 8–12 帧；全程叠 10–15% 挤压拉伸和轻旋转掩盖插值的机械感；速度曲线中段最快 `cubic-bezier(0.7,0,0.3,1)`，起止各留 3 帧；用 flubber 等库做顶点匹配插值。
- **声音**：律动拨奏琶音；每次形变落拍一道带音高的 whoosh。

### 几何构成 / 包豪斯 Bauhaus
- **是什么**：圆、三角、矩形在严格网格上精确平移旋转缩放，三原色 + 黑白。动态海报主流语言。
- **标志**：基础几何形、红黄蓝黑限定色、严格网格对齐、绕几何中心旋转、节拍驱动的模块化运动。
- **技法**：位移 = 网格模数整数倍，落点必在网格线上；缓动克制（easeInOutQuad 或匀速），**禁用过冲**——机械感是特征；每个元素在拍点瞬时出现/翻转，一拍一个动作；旋转轴心在自身中心、边缘顶点、画面中心三种之间交替；可用三角函数相位差批量驱动阵列。
- **声音**：极简 techno/click：每次翻转一个带音高的 click，四分音符 kick。

### 复古 Synthwave / VHS / Y2K
- **是什么**：80s 霓虹网格 + 日落渐变 + 镀铬字；VHS 扫描线色偏噪声；Y2K 液态镀铬、酸性绿紫、拟物窗口。
- **标志**：霓虹辉光、透视网格地平线、扫描线与 RGB 色偏、镀铬金属字、酸性配色、拟物窗口 UI。
- **技法**：一点透视网格纵向循环滚动 + 多层渐变日落球 + 双层辉光（内层紧 4 px 高亮、外层散 30 px 低透明）；VHS 链：红蓝通道各偏 1–2 px → 2 px 间隔 10% 黑扫描线 → 每秒 1–2 次波浪扭曲/抽帧 → 4:3 圆角遮罩；镀铬字：高对比多段金属渐变 + 斜面高光 + 环境反光 + 镜头光晕；Y2K 运动语言：弹窗 pop、光标点击、窗口拖拽；关键段落抽到 15 fps 或倒放 2 帧制造磁带卡顿。
- **声音**：gated-reverb 军鼓、琶音锯齿贝斯、厚 pad，标题砸下时大和弦 + 镲。

### 弥散渐变 / 玻璃拟态 Aurora & Glass
- **是什么**：大面积模糊色斑缓慢漂移作底，磨砂半透明玻璃卡片浮在上面。科技/AI 品牌片近年的默认视觉，气质“慢、透、高级”。
- **标志**：大色斑模糊漂移、磨砂玻璃卡片、1 px 高光描边、邻近色低对比、缓慢呼吸节奏。
- **技法**：3–5 个纯色大圆 blur 80–150 px 沿贝塞尔路径 20–40 s 漂移循环；玻璃卡：`backdrop-filter: blur(20–40px)` + 白 5–10% 填充 + 1 px 白 30% 内描边 + 大圆角；邻近 2–3 色（紫蓝青 / 橙粉红），撞色会脏；暗底亮斑比亮底好；全局 3–5% 噪点防色带；缓动接近 linear 或 sine，**一切都慢**，文字入场只用透明度 + 8 px 位移。
- **路线**：WebGL mesh-gradient 着色器 + SDF 透镜折射（色散）+ DOM 玻璃卡。
- **声音**：电影感氛围垫、柔和闪烁、极轻的 UI tick。

### 综艺花字 Hanazi（竖屏 1080×1920）
- **是什么**：电视综艺后期的情绪化装饰字幕：多层描边圆体字弹性入场、跟着情绪变色变形、配打击音效；现在是 vlog、萌宠、访谈、搞笑二创的通用包装。
- **标志**：多层描边圆体/胖体字、高饱和撞色 + 白边 + 投影、弹性 pop 入场、跟音效同时出现、手绘装饰符号（爆炸框、汗滴、闪光）。
- **字的层结构**（SVG 里同一段文字叠多层，从下往上）：两层同色挤出（向下偏移，做厚度）→ 彩色外描边（最粗）→ 白色粗描边 → 渐变填充 → 顶部高光。全部 `stroke-linejoin: round`。CSS 可用 `paint-order: stroke fill` + 多层 `text-shadow` 近似。
- **入场**：scale 0 → 1.15 → 1.0 约 8 帧，或逐字弹跳错开 2 帧，带轻微旋转；**比笑点/语音晚 2–3 帧出现更自然**；长时间停留的字加轻微 wiggle 保持活性。
- **情绪匹配**：吐槽用歪斜手写体（如“（小声）”）、惊讶用放射线爆炸框 + 速度线（“震惊!!”）、疑惑用弹跳的问号（“？？？”）、尴尬用汗滴、夸赞配闪光（“绝绝子”）、盖章（“××认证”）。
- **底层**：像素材的画面（公有领域/CC0 宠物或人物照片做缓慢推拉 + 轻手持 + 笑点处快速 punch-in），或风格化场景。
- **配色**：高饱和粉、黄、青 + 白边 + 深紫/深蓝描边线。字体用圆体/胖体（找 OFL 授权的中文圆体，按用字子集化）。
- **声音**：蹦跳的综艺底（拨弦、贝斯、拍手）+ boing、pop、ding、滑哨、唱片刮擦（配“？？？”）。
- **注意**：中文必须地道、全角标点；花字不能挡主体的脸和关键动作。

### 粗描边贴纸人科普 Sticker Explainer
- **是什么**：知识区标准包装：实拍图抠图加粗白边变“贴纸”，与扁平图标、数据图表铺在大画布上，镜头平移缩放串联信息点。
- **标志**：照片贴纸化（粗白描边）、蓝灰/米白冷静底色、扁平图标 + 精确图表、大画布运镜、信息密度高的节拍化叙事。
- **技法**：抠图 + 8–12 px 白描边统一质感；超宽大画布（如 6000×3000），相机层长缓动平移缩放，一镜串多个信息点；柱状图生长、数字滚动、路径描边生长；解说逐句驱动元素入场，每句必有新视觉；2–3 色 + 等线字体保持严肃。
- **声音**：干净的科技解说底、UI click、计数时 tick、运镜时轻 whoosh。

### 像素风 Pixel / 8-bit
- **是什么**：低分辨率大颗粒像素 + 有限色板 + 低帧率精灵动画。
- **标志**：硬边像素、8–32 色色板、8–12 fps 精灵帧、抖动渐变（dithering）、可选 CRT 扫描线。
- **技法**：内部分辨率 320×180，整数倍（×6）最近邻放大（`image-rendering: pixelated`），杜绝抗锯齿；精灵帧循环（走路 6–8 帧、呼吸 2–4 帧）；动画用阶梯时序不用平滑缓动；远中近三层整像素视差；CRT：扫描线 + 桶形畸变 + 磷光辉光。不加胶片颗粒。
- **声音**：chiptune（方波主旋律、三角波贝斯、噪声鼓）+ 跳跃/金币/宝箱音效。

### 赛博朋克 HUD / FUI
- **是什么**：科幻电影/游戏界面的抬头显示：青橙霓虹线框、锁定框、雷达扫描、数据流小字。
- **标志**：青/橙霓虹线框、锁定框与十字准星、环形雷达扫描、等宽小字数据流与打字机、六边形网格与辉光。
- **技法**：线框生长用 dashoffset 描边，按层级错帧展开；雷达：conic-gradient 扫描扇区旋转 + 目标点闪烁；数字先随机跳 3–5 帧再落真值（种子随机）；打字机 + 光标闪烁；锁定框四角括号 scale 1.4 → 1.0 快出缓入吸附目标；全局外发光 + 轻色差 + 扫描线统一质感。
- **声音**：darksynth 脉冲 + HUD beep、扫描 sweep、上升的锁定音、锁定时警报。

## B. 更多风格（一句话索引）

需要时按 `style-spec.md` 现场写完整说明。括号里是该风格最该守住的东西。

**剪辑与纪实**（用真实档案素材，素材授权先核）
- 字幕新闻：静音也能看懂的社媒新闻，巨大字幕一块块砸进来，关键词压黄块，数字滚动，出处标签随数字出现。（字幕是主角）
- 1920s 新闻影片：探照灯地球台标、铜管开场、旋转报纸、地点日期卡，欢快的解说。（时代质感，不加假划痕滤镜糊弄）
- 实时倒计时分屏：一个有确定零点的事件，屏幕时间 = 事件时间，时钟每秒走，画面越分越多格。（时间真实）
- 延时交响：城市延时被剪成极简音乐，切点随配乐细分越来越密，一个东西慢到几乎停住，落拍硬切黑。
- 视觉调查：同一事件的视频、照片、文件、声音、地图放在同一条共享时钟上互相印证。（时钟活在画面里）
- 构成主义蒙太奇：档案影像印成一张单红油墨海报，斜带承载字，机器节拍剪辑。
- 体育战术板：全速播放 → 倒回 → 定格 → 在转播画面上画圈、箭头、空当色块。
- 电视新闻包装：台标 sting、串联单、常驻下三分之一条、全屏图表。

**实证影像**（每个数字有出处，建 `FACTS.md`）
- 卫星简报：真实卫星图调成分析员灰，细白测量线、锁定框、一个读数，连续缩放。
- 工程简报板：拍下来的一面白板墙，真实物件照片剪下来带重量落上去，三色马克笔各有固定含义，最后拉远看到整面墙。
- 点云测绘：真实激光点云漂在黑暗中，扫描线穿过后凝结成实体表面，再用发丝线仪器测量。
- 白模投影：纯白体块模型上，投影仪一层一层把数据当光投上去；模型不变，只有光变。
- 数据实物化：每个数据单位是一块可数的实物（盘、块、币），按精确比例堆在底座上，像产品一样打光。
- 产品拆解：用真实工程文件建模，像棚拍产品一样打光，沿一根轴逐层抬起，每个零件标出名称和数字。
- 显微叙事：真实显微图像，一次连续的尺度变化从手里的玻片推到一个细胞，换倍率时焦点呼吸。
- 档案灯台：玻璃底片、信件、电报平放在冷色灯台上，放大镜落下的地方物件活过来。

**手绘与绘画**
- 蜡笔绘本：粗纹纸上实时画蜡笔，水彩刷过时显出蜡笔藏住的东西。
- 水彩笔刷：自己画自己的手账页，半透明笔触带飞白，旁边手写注记，没有矢量线。
- 中国水墨：宣纸上的写意，留白是空间，一笔是山、是浪、是一个动作、也是一次切换。
- 油画厚涂：刮刀厚涂的大块锐边色面，侧光照出每道颜料脊；先明暗结构后肌理，焦点硬边其余平静。
- 一笔画：一根墨线从不离纸，场景不切，靠变形转换。
- 白板讲解：白板上逐笔写出的单线手写，悬空马克笔、可移动磁贴、可倒带的板擦，相机在板上移动。
- 钢笔淡彩：现场写生本，褐色针管笔线条抖、过头、不闭合，透明水彩落在线外一点。

**东方传统**
- 皮影戏：半透明染色兽皮偶，镂空如蕾丝，贴在棉布幕上被油灯从背后照亮。
- 浮世绘：平涂色块、刻线、天空晕染（bokashi）、可感的纸，相机像展开手卷一样移过画面。
- 红色窗花剪纸：有关节的红色剪纸，剪口就是线条，镂空处透光。
- 纸雕灯影：6–9 层切纸叠在浅盒里，背后暖光透过，孔洞里烧出月亮和窗，每层投影落在下一层。

**印刷与版画**
- Risograph：两三种半透明专色叠印在暖纸上，网点、油墨颗粒、永远对不准的套版。
- 复古半调案卷：奶油色档案纸、少数几种平涂油墨网点、错位阴影的巨大标题、砸下的橡皮章。
- 木刻版画：黑色木版上刀刻出的地方才有光；最多一种颜色，只给“燃烧的东西”。
- 铜版画：刻刀在铜板上刻出渐粗的线，轮廓 → 排线 → 交叉排线逐步建立，最后拓出成品。
- 丝印旅行海报：4–6 种不透明平涂油墨一色一色刮上去，用色阶代替渐变，套版缝露纸白。

**图形与排版**
- 瑞士动态排版：模块网格、一种字体、一个信号色，动作精确得像印刷机。
- 60s 间谍片头：剪纸四色片头，剪影在由演职员表搭成的布景里移动，每一下铜管就是一刀剪辑。
- 装饰艺术：黑漆、刻金线、喷枪几何，每个构图有中轴，灯泡一个个亮起。
- 蓝图：普鲁士蓝晒图纸上的白色工程线，按制图顺序画出，注记会动。
- 彩色玻璃窗：暗石厅里的中世纪彩窗，只有阳光照到的地方才活；光是时钟、相机和故事。
- 象形运动图形：节拍锁定的闪卡片：方格核心图形、圆头条与圆盘头组成的象形人、粗体双语字。
- ASCII / CRT：屏幕上一切都是单色 CRT 磷光照亮的等宽字符。

**信息与发布**
- 数据叙事：奶油纸上红蓝铅笔一笔笔画出真实数据，手写注记钉在数字上，图表本身就是相机和情节。
- 等距信息图：扁平三色体块的等轴系统图，东西会打开露出内部，数字是画出来的不是说出来的。
- 暗色科技发布：近黑渐变、发丝网格、柔光、一个品牌强调色，UI 以吸附网格的精度运动，一个巨大数字。（产品片路线的近亲）
- 活体实机录屏：看起来像真实录屏，一个低分辨率吉祥物住在高分辨率界面里演出软件在做什么。
- 科幻全息：物体被扫描成发光线框，锁定框咬住部件，局部爆炸视图，数字从乱码滚成真值。

**卡通与动画**
- 1930s 橡皮管卡通：黑白手绘，万物都活着，跟着热爵士乐摇摆。
- 80 年代赛璐璐：平涂双色赛璐璐 + 喷枪背景、逆光霓虹、有限动画节奏，像 80 年代录像带在 CRT 上播放。
- 科幻情景喜剧卡通：粗沸腾轮廓、平涂、反应不同步的二人组、发光传送门、每个世界一套色板。
- 50s 扁平卡通：色块错开断线墨线、身体不动只有手在动、抽象色块房间、平静的旁白、冷爵士。

**游戏**
- 16-bit 像素 RPG：320×180、有限调色板、会打字的对话框、菜单、存档、带回声的芯片音乐。
- HD-2D：手绘像素精灵像纸片立在有光有雾的 3D 立体模型里，高位 3/4 视角 + 移轴。
- 微游戏快闪：一个指令词、几秒、一个动作；每个小游戏一种完全不同的画风，越来越快。
- 综艺节奏扁平：粗墨线玩具感吉祥物、糖果色条纹和放射光，每个命中落在固定节拍网格上，一问一答，赢了打出判定词。

**电影与时代**
- 1920s 默片：版画式插图默片，墨线 + 银色淡彩，4:3 画面闪烁晃动，字幕卡代替对白，影院钢琴伴奏。
- 后室 / 新怪谈：从空旷、无尽、日光灯照明的空间里找回的摄像机录像带；规则代替怪物。

**材质与 3D**
- 积木玩具：像微距摄影拍真实桌面上的定格积木片，一个姿势一个姿势地动。
- 纸片立体书：真实桌面上的立体书变舞台，白边纸片演员在弹起的纸布景前表演，真实台灯和微距镜头。
- 移轴微缩：高处用移轴镜头延时拍的真实地方，整个世界读作桌面模型。
- 低多边形等距岛：正交等轴镜头下的小切面世界，每样东西出现时带一下弹跳和一个音符。
- 玻璃质感产品：暗场棚拍里的透明/磨砂玻璃产品，条形光扫过、色散、焦散、光在物体内部游走，慢速爆炸视图在落拍时合拢。
